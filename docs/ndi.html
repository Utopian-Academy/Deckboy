NDI out,
NDI in

A cue list whose pictures leave over the network, and anyone else's NDI source played like a clip — free, on Windows, macOS and Linux.

What it is for

A cue list whose pictures go out over the network instead of down a cable: into a vision mixer, a streaming PC, a recorder, an LED processor with an NDI input, or another machine running Deckboy. And the other way round: somebody else's NDI source — a camera, a graphics machine, a laptop on stage — taken as a cue and played like a clip.

Send

  1. Install NDI Tools on the machine. It is free, from the people who make NDI, and it carries the runtime Deckboy loads. Without it Deckboy says NDI is unavailable rather than failing quietly.
  2. Add an output and turn on NDI. It appears on the network as an NDI source, and it can send a separate key source for the alpha.
  3. Take cues as usual. Every output keeps its own settings, and each output can show a different deck, so one machine can send several different pictures as several NDI sources.

Receive

SOURCE → NDI Source Cue puts an NDI source in the cue list. It fades, holds and takes effects like any other cue, and it can be the inset of a picture-in-picture cue over whatever else is live.

Platforms

NDI input and output are in every published build for Windows, macOS and Linux. --self-check prints ndi-sdk: headers detected when NDI is in the build, so it is one command to be sure.
