Why the answering back matters

A key that only sends a command cannot tell the operator whether the cue went live. The Companion module asks Deckboy for its status several times a second, so the button for the cue on air lights red, the next cue shows green, and a button can carry the time left in the clip — the "wrap it up" number the stage manager wants.

Setting it up

  1. Download the latest release. The plugin and the module are in it, beside the downloads for each platform.
  2. Install the one you use (both work at once).
  3. Connect to Deckboy's control port, 5510 by default. Deckboy listens only to its own machine until you turn on REMOTE in its network settings, which is what lets a Companion on another computer in.
  4. Drag in a preset: transport, a now-playing button with a countdown, output controls, and a cue button with tally to duplicate for each cue.

Without a Stream Deck

The same control port takes plain text commands from anything that can open a TCP connection, and Deckboy also answers OSC, MIDI and MIDI Show Control, and chases LTC timecode. Send HELP to the port for the whole vocabulary.
