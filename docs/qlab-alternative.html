A free QLab alternative
for Windows and Linux

QLab runs only on a Mac. When the show machine is a PC, or the venue has a mixture, Deckboy is a cue list with a GO button that runs on Windows, macOS and Linux from one show file, and takes its cues from the lighting desk.

Deckboy is independent open-source software. It is not affiliated with QLab or Figure 53. QLab is very good, and if your show machine is a Mac and your show is mostly sound, you should probably use it.

The short version

Deckboy started as a video cue deck and grew toward show control. It is strongest where the show is pictures: clips, stills, slide decks, cameras, a window on the machine, a web page, NDI and SRT feeds, all as cues on one list, out to a projector, an LED wall, NDI, SRT or SDI. It plays audio cues too, but QLab is the deeper audio tool.

Fired from the lighting desk

In most theatres the lighting desk is the master and everything else follows it. Deckboy answers MIDI Show Control: an ETC Eos or a grandMA sends GO with a cue number, and Deckboy takes the cue with that number. MSC cue numbers are text, so 12.4.1 and A both work. STOP, RESUME, LOAD, ALL_OFF and RESET are honoured, and so is MIDI Machine Control. The device ID match is exact, so Deckboy does not answer a message meant for the rest of the rig. MIDI is in the Windows and Linux downloads; the current macOS download does not include it.

It also takes OSC, MIDI notes and controllers, Art-Net and LTC timecode, and it can be run from a Stream Deck or Bitfocus Companion.

What Deckboy does not do

  • Sending show control. Deckboy is fired by other devices: MSC, OSC, MIDI, Art-Net and timecode all come in. It does not yet send MIDI, OSC or DMX to other equipment from a cue.
  • Pre-wait, post-wait and cues that act on other cues. Cues run in order and can move on to the next when they end, but there are no wait times and no start/stop/fade cues that target another cue.
  • Group cues, devamp and memo cues.
  • Microphone cues. There is no live-mic cue with its own processing.
  • A lighting system. Deckboy is not a lighting console.
  • Scripting. There is no script cue. Other software drives Deckboy through its text control protocol instead.
  • Years in the field. QLab has a long record in theatres. The show-control side of Deckboy is new, so run it next to the version you trust before it runs a show on its own.

Where Deckboy goes further

  • It runs on the PC you already have, and on Linux, from the same show file as the Mac.
  • Every feature is free on every machine. No licence per computer, so the backup machine in the flight case has everything the main one has.
  • The picture leaves in more than one shape. NDI, SRT, RTMP, Blackmagic SDI and SMPTE ST 2110, while it records.
  • A window or a web page is a cue. A rehearsal timer, a surtitle page or a score bug goes to air without a capture card or a second machine. How window cues work.
  • Slides are cues. PDF, PowerPoint and Keynote import one cue per slide, with presenter view as an output of its own. Slides and presenting.
  • Test patterns for the projector and the LED wall are built in. The free pattern kit.

Trying it on a show

Download the stable release, build the cue list, and point the desk's MSC output at the show machine with Deckboy's device ID set to match. The manual covers MIDI Show Control and every cue type. As with anything new to a rig, run it through a tech rehearsal before it runs a show.
