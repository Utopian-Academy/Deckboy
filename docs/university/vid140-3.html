DHCP or static?

DR. PIXEL

Who gives a device its address? There are two ways. DHCP: a server on the network gives one out automatically. Static: you type it in.

Now a fault that you will see, skapi. There is no DHCP server, so the device gives itself an address that starts with 169.254. That address is the clue: it means "I asked, and nobody answered".

Try it: what address does it get?

Address:

DR. PIXEL

My rule for a show: anything that other devices must find gets a static address. Cameras, playback computers, the lighting desk, control surfaces. If an address changes during the show, the button that points at it stops working.

Write the addresses on a sheet of paper and tape it to the rack. DHCP is fine for a laptop that only needs the internet.

PROF. VIDEO

A static address is like a labelled patch point. You can find it in the dark. DHCP is like asking who is free tonight. Friendly, but not at 8 pm.
