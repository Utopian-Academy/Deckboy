Ports and firewalls

DR. PIXEL

The address gets you to the building. The port gets you to the right door. Each program listens on a port. A firewall is the guard who decides which doors open.

So you can ping the computer, and the software still cannot connect. Most of the time, that is the firewall.

Try it: get the message through

DR. PIXEL

There is a trap. When Windows first meets a network, it can call it Public, and then it blocks more. A show switch with no internet often lands there. Set it to Private. And let the app through.

Do not turn the whole firewall off, skapi. Open what you need.

PROF. VIDEO

Some numbers to know: Art-Net uses UDP port 6454. sACN uses UDP 5568. mDNS, which helps devices find each other, uses UDP 5353. OSC has no fixed port, so both ends must agree. That one has confused me personally.
