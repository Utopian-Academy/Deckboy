An address for every box

DR. PIXEL

Dobar den, skapi. Here is the job. The laptop cannot see the camera. Both are plugged into the switch. The lights on the switch are on. What now?

Now you check the addresses. Every device on a network has an IP address: four numbers, like 192.168.1.20. For two devices to talk directly, the first part must match, and the last number must be different.

Try it: make them all see each other

Change the addresses. All four use the mask 255.255.255.0, so the first three numbers must match.

DR. PIXEL

You found two faults. The camera and the lighting desk were on different networks, so nobody could reach them. And two boxes had the same address. That is a conflict, and it causes strange faults that come and go. Each address can be used once.

PROF. VIDEO

It is like patching two modules to one output socket, and expecting each to get its own signal. I have done that. Also, lighting desks often start on 2.x.x.x, because Art-Net once suggested that range. Do not be surprised.

DR. PIXEL

For a show network, use a private range. 192.168.x.x and 10.x.x.x are the common ones. They are reserved for private networks, so they do not clash with the internet.
