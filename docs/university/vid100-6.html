From source to screen

DR. PIXEL

Last lecture of this course, skapi. Every video system is a chain. A source makes the picture. A cable or a network carries it. A screen or a projector shows it.

When there is no picture, do not panic. A chain has links. You check one link at a time.

Try it: break one link

DR. PIXEL

Several faults look the same. That is the point. "No signal" does not tell you which link broke. So work in order:

1. Does the source show the picture on its own monitor?
2. Is its output on?
3. Does a short, known-good cable work?
4. Is the screen on the correct input?
5. Does the screen accept this format?

Change one thing, then look. If you change three things and it works, you learn nothing.

PROF. VIDEO

This is how I find a fault in a patch. Start at the oscillator. Listen at each stage. The signal is there, and then it is not. The fault is between those two points. I had that in my head the whole time.
