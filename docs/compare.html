How Deckboy compares

Including the jobs where something else is the better answer.

Deckboy is an open-source, cue-based media playback and show-control application for live video. It is not trying to be all of the tools below, and for several jobs one of them is plainly the right call. This page tries to say which is which.

Where Deckboy tends to fit

  • You are not on macOS. QLab is macOS-only, and it is the reason "QLab for Windows" is such a common search. Deckboy runs natively on Windows, macOS and Linux from the same show file.
  • You want the cue list and the outputs in one window. CasparCG is a server that expects a separate client to drive it. Deckboy is a single application an operator sits in front of.
  • The signal has to leave the machine in more than one shape. NDI, SRT, RTMP, Blackmagic SDI and SMPTE ST 2110 can run at the same time, so a playback machine often solves the conversion problem on the day as well.
  • It has to be driven from a surface. There is a Stream Deck plugin and a Bitfocus Companion module, plus OSC, MIDI, Art-Net and LTC timecode.
  • Budget is zero. It is GPL-3.0 with no account, no licence server and no telemetry.

Where something else is the better answer

This section is here on purpose. Recommending the wrong tool wastes a show day.

  • Audio-led theatre cueing on a Mac — use QLab. It has years of refinement, a deep audio cue model and lighting cues in the same stack. Deckboy is video-first and does not do lighting cues.
  • 24/7 broadcast playout with a rundown — use CasparCG or ffplayout. They are built for unattended channel operation and automation systems talk to them already.
  • Large projection-mapped installations — use Watchout, Millumin or Resolume. Deckboy has warp, keystone and edge blend per output, which covers ordinary multi-projector work, but it is not a mapping suite.
  • Lyrics, scripture and worship flows — use ProPresenter. Deckboy imports PDF, PowerPoint and Keynote decks and has presenter and prompter views, but it has no song or scripture library.
  • Compositing and streaming a live programme — use OBS or vMix. Deckboy is a source and a player, not a switcher. The two pair well: Deckboy out over NDI, OBS ingesting it.

Honest caveats

  • The builds are not code-signed. Signing needs paid Apple and Microsoft developer accounts that the project has not bought, so macOS and Windows will warn about an unknown developer. The README explains the one-time steps.
  • It is a young project compared with anything else on this page, and it has not been through the number of show days those tools have.
