What is in it

  • Cue-based playback and thirteen cue-to-cue transitions.
  • Six effects that exist in no other player, a bar each: schlieren imaging, Chladni figures, a real wave equation, crystal grain growth, retinal rod and cone persistence, and structure-tensor grain flow.
  • Databend — the picture read out as a signal and played through an audio chain. You can try that one in your browser.
  • A live application window taken as a cue, and a live web page taken as a cue. How the window one works.
  • Slides as cues, with presenter view on its own output.
  • An everything-at-once ending, which is what the application looks like when somebody stops demonstrating it and starts playing with it.

How it was made, which is the joke

There is no footage of anybody using Deckboy in this trailer, because nobody used it. The whole performance was scheduled against a beat grid and fired down the same TCP control port a Stream Deck or a Bitfocus Companion button would use — TAKE, FX ADD databend 72, SOURCE WINDOW title:LIVE NOW — one command at a time, on the beat, for forty seconds. The mouse was not touched.

The picture is Deckboy's own control window, captured at its real size. The window cue you see going to air is a real browser window sitting off to one side of the same desktop; the web page cue is a real page being rendered inside the programme. Nothing is a mock-up, and nothing is anybody's media — every picture in it is generated by Deckboy itself, so no client's show file appears anywhere.

The music is the application too

The tune is played on Deckboy's 2A03 chip voice — a Tone cue, the same one an operator would use to check a PA — four passes for lead, counter-line, bass and drums, each fired down that same control port and recorded by Deckboy's own recorder. It is tuned to A = 432 Hz, which is a field in the cue rather than something done to the file afterwards.

The mix then went back into Deckboy as a cue and out through its own audio rack — tilt, crush, a CD-skip stutter, delay, reverb, width and a compressor — and that is what you are hearing: a bright, swung chip tune over a chopped break, at 145 bpm.
