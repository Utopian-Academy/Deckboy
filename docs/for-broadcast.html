Cue playback
for the IP plant

A playback server that speaks NDI, SDI, SMPTE ST 2110, SRT and RTMP, takes other machines' feeds in as cues, and answers the control protocols your gallery already uses.

The programme going out as an NDI source while it records, then another machine's NDI graphics taken in as a cue. Recorded from Deckboy 0.99.397. Music: YMCK, used with permission · vertical version

Out

  • NDI, in every download, with key and fill.
  • Blackmagic DeckLink SDI, including key and fill down two outputs for a downstream keyer.
  • SMPTE ST 2110-20 video and -30 audio, with AMWA NMOS IS-04 and IS-05 so a broadcast controller can find and route it, and PTP (SMPTE ST 2059) for the media clock.
  • SRT and RTMP streams, each output with its own destination, while the programme records.

In

NDI sources, SRT, RTMP, RTSP and UDP feeds, and DeckLink capture are cues like a clip: same transport, same transitions, same effects, same remote control.

Controlled the way the gallery already works

  • HyperDeck protocol, so a deck controller or vision mixer can drive it.
  • Answers the vMix HTTP and TCP APIs, so panels built for a vMix rig work unchanged.
  • Tally: TSL out, ATEM and NDI-metadata triggers, so it can roll when it is put on air.
  • LTC chase and generation, and a plain-text control port where every command answers OK or ERR.

The details, format by format, are on the specifications page.
