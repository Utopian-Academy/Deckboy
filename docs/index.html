Cues, in order

Drag media in, trim it, fade it, loop it, and let it hold its last frame. Black is a decision. Revealing your desktop to four hundred people is a confession.

📡

It speaks in tongues

NDI, SRT, RTMP, Blackmagic SDI and SMPTE ST 2110, several at once, plus warp and edge blend per output. An unreasonable quantity of protocol for what is, at heart, a box that plays telly.

🎛️

Somebody else’s finger

Stream Deck, Bitfocus Companion, OSC, MIDI, Art-Net and LTC timecode. The keys read the state back, so the button knows whether the cue it fired actually went — rather than merely hoping, as we all do.

🛠️

And the rest of it

Converts media that refuses to play, normalises a clip mastered too quietly to EBU R128, imports a PowerPoint as one cue per slide, and generates test cards. Yes, there is a video synthesiser. Yes, there is a Famicom sound chip. No, nobody asked for either.

Presenter view is an output type of its own, so it takes its own display — live slide, the one before, the one after, the notes and the clock.
