Questions

The ones that actually get asked before a show.

Is there a free NDI player for Windows?

Deckboy sends and receives NDI on Windows, macOS and Linux, at no cost. An NDI source can be added as a cue and played like any other clip, and any output can send NDI while also sending SRT, RTMP, Blackmagic SDI or SMPTE ST 2110 — simultaneously, not instead of each other.

Manual: Outputs & Routing

Can I use my own plugins?

Yes — Deckboy hosts VST3 effects and instruments inside a cue's audio chain, alongside its own effects and in whatever order you put them. Add a Plugin effect and pick from what is installed on the machine. Instruments are played from the computer keyboard, a MIDI keyboard, or a controller over the network — the same three ways Deckboy plays its own chip synth.

Four of the plugin's parameters appear on Deckboy's own rows beneath it, under the plugin's names for them, and everything else the plugin was set to is saved with the show. There is no plugin editor window — the controls are Deckboy's rows, not the plugin's interface. Plugins are opened when a cue is prepared rather than between two buffers, and one that cannot keep up with its block is removed from the chain and reported instead of clicking through the PA. A show opened on a machine that does not have one keeps the slot and its settings and names the missing plugin. Run --plugins to see what a machine has and where it looked.

Manual: Audio

Do I need the NDI SDK, or a paid NDI licence?

Neither. NDI is in every download. What a machine needs is the free NDI Tools runtime from the people who make NDI — Deckboy loads it if it is there and says NDI is unavailable if it is not, rather than failing quietly mid-show. Nothing is bundled that is not ours to give, and nothing is charged for.

Manual: Outputs & Routing

How do I put a live application window on a projector or LED wall?

Add a window cue and pick the window. The application arrives at its own full resolution whatever your display scaling is set to, scaled to fit the frame, follows the window as it moves and resizes, and is not interrupted by anything in front of it — so the operator can keep working on the same machine without it going to air. Rehearsal tools, score bugs, timers and the spreadsheet somebody insists on all become cues with the same fades and effects as a clip.

Can I show a web page, dashboard or scoreboard as a cue?

Yes. A browser cue renders the page inside the programme, not in a browser window on your desktop, so there is no window to keep on top and nothing to reveal by accident. It fades, takes effects and goes out over every output at once — screen, NDI, SRT, SDI — like any other cue.

Manual: Cue Types

How do I loop a video on a screen all day?

Import the clip, set the cue to loop, and send the deck to a fullscreen output on the display you want. When a cue ends Deckboy holds the last frame rather than revealing a desktop, which is the failure everybody has seen in a foyer. There is also a soak mode (--soak) that logs memory and stalls, so a machine can be proven before it is left unattended for a week.

Manual: Playlists, Loop, Shuffle & Cue Endings

Can I trigger playback from a Stream Deck?

Yes — there is a Stream Deck plugin and a Bitfocus Companion module. Both poll Deckboy's status, so a key carries tally, transport state, output health and a countdown: the button knows whether the cue it fired actually went live, rather than just hoping. OSC, MIDI, Art-Net and LTC timecode work too.

Manual: Remote Control

Can I play PDF or PowerPoint slides from a cue list?

Yes, and this is the thing Deckboy does that the other cue players do not do at all. A PDF, PowerPoint or Keynote deck imports as one cue per slide, sitting in the playlist next to the video and the audio, fired by the same keys, the same Stream Deck, the same timecode.

Every page is rendered once on the way in, by the platform’s own engine — Edge’s on Windows, Preview’s on macOS, pdftoppm on Linux — so during the show a slide is just a picture. Nothing depends on a document program still being open, still being on the right slide, or still being in the foreground.

Speaker notes come in with the deck. Presenter view is an output type of its own, so it takes its own display: live slide, the one before, the one after, the notes and a clock. So is a mirrored prompter that scrolls at a pace you set. The alternative most rooms are still using is a second laptop and a long cable.

PowerPoint's own export flattens builds and drops transitions — that is the export, not the deck. So a presentation that genuinely has to animate runs in PowerPoint and goes to air as a window cue: you keep every build, and it still fires from the cue list with the same fades as everything else.

A client sent a file that will not play. What now?

Convert it in place, without leaving the application, with GPU encoding where the machine has it. Importing any file also reports codec, raster, frame rate, channel count and duration, so you can see what you were actually sent. If a clip was mastered too quietly it can be normalised to EBU R128.

Is there a Mitti, PlaybackPro or QLab alternative for Windows?

That is most of the reason Deckboy exists. Mitti, PlaybackPro Plus, QLab and Millumin are all macOS only, and vMix is Windows only, so the first question on a show is usually whether the software runs on the machine you brought at all. Deckboy runs natively on Windows, macOS and Linux from the same show file.

Where the others still win: Mitti is the most refined cue player on a Mac, PlaybackPro has years of corporate rooms behind it, QLab owns audio-led theatre cueing, Millumin is a real projection-mapping suite, and vMix is a switcher, which Deckboy is not. There is a fuller comparison here, including where each of them beats it.

Is it really free, or is there a paid tier later?

Free, GPL-3.0, no paid tier and no plan for one. No account, no licence server, no telemetry, nothing that phones home — which is a reliability argument as much as a principle, because a licence check is one more thing that can refuse to start a show at 19:55.

First run: because the builds are not code-signed, Windows and macOS show an unknown-developer notice once. It takes one click to get past, and the README has the steps.

Can I run more than one screen from one machine?

Yes. Outputs are per-display, with display-native or fixed raster modes, and each output has its own area of interest, edge feathering and warp / keystone correction — enough for ordinary multi-projector work, though it is not a projection-mapping suite.
